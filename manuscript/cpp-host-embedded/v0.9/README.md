完整候选版0.9，2026年10月6日。面向具备基础编程能力、尚未系统学习现代C++与硬件的读者。全书24章，以低压温度监测节点及测试校准工站贯穿公共基础、Qt工业上位机、MCU与RTOS、嵌入式Linux和综合故障推理。

## 使用和验证边界

所有软件、固件、命令和配置片段均是教学说明，未编译、未运行、未连接硬件。具体芯片、板修订、操作系统、Qt、编译器、厂商SDK和仪器组合，仍需在实际项目中补齐验证。低压教学边界与仪器前提见第16章，不用于市电、高压、大电池或危险运动设备的入门操作。

正文以原书book-v1.1.0的固定提交0842f624995d2fd99f46c68426c9a33a73610cbb为迁移基线。原58章全文身份、逐节保留和重写去向在来源清单与修订记录中保存。source-inventory.json中的path为固定提交的原仓库路径，原58章全文不随本包重复复制。本包没有覆盖原书正文或历史版本。
