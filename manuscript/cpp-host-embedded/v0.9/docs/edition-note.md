# 版次与验证边界

本书为《C++ 上位机与嵌入式工程入门》完整候选版 0.9，编辑日期为2026年10月6日。它从原书已验收的 book-v1.1.0 重新选材与写作，基准提交为0842f624995d2fd99f46c68426c9a33a73610cbb。新书独立保留24章顺序；原书58章和历史发行不因本版移出某条路线而删除。

## 本版可以支持的结论

原书58份章节全文已按固定提交取得，并逐份比对 Git blob 身份与文件长度，建立 SHA-256 清单。正文迁移按实际原节标题记录，新增说明、重写、合并和移出分别说明理由。来源记录中的“全文取得”和“技术资料核验”是不同证据；取得全文不自动意味着原有技术结论全部适用于新版平台。

新版以章节 Markdown 为权威正文，图像、资料、术语与出版顺序随源稿一起保存。PDF 和 EPUB 是由同一份章节内容生成的阅读制品。独立文档生成和制品检查并不代表原仓库出版流水线已经支持新章号、新目录或新版发行标签。

## 没有执行的验证

本版全部代码片段、CMake示意、命令示例、固件和Qt行为示例均未作为工程编译或运行；没有厂商SDK接入测试，也没有对真实工站数据库、PLC或MES进行写入。未执行真实硬件接线、采样、故障注入、波形、功耗、校准或安全测量。章节中的故障经过和数值算例是推理示范。

因此，本书是完整的入门解释与技术阅读材料，不是开箱即用的产品源代码，也不是设备验收证书。真实项目应把工具链、版本、硬件身份、接线、负载和许可条件固定后，按章节给出的证据要求补齐自己的验证记录。

## 资料随时间变化时

正文尽量指向具体版本资料。滚动文档可能在出版后更新，读者应先核对自己使用的版本，再判断新增行为是否适用。Qt API 以6.8文档为基线，涉及关闭语义的细节还参考6.8.3实现；不能把后来在线文档里的更强表述自动追认给旧二进制。MCU芯片参考手册、板卡手册、勘误和实际板修订也需要分别识别。

详细修改意图、逐节迁移、素材身份、技术审校、制品检查及尚未执行项目见随附的《完整候选版修订与来源》。该报告与正文分别交付，避免阅读主线被长篇编辑记录打断。
