# 环境与共同案例约定

这里固定的是阅读文稿所依据的平台与术语，不是一套已经编译、运行和验收的交付环境。真实项目要在相同身份信息之外补齐工具链、依赖、操作系统镜像、板卡修订和实际测试证据。

## 软件说明基线

C++20 是公共概念基线。某项能力是否存在，要同时检查语言模式、编译器、标准库、目标 ABI 和运行环境。讨论 C++23 的 std::expected 时会单独标注，不能把它混入默认 C++20 片段。桌面操作系统提供的进程、线程与文件接口，也不能直接假设存在于裸机固件。

上位机采用 Qt Widgets、QObject 工作对象与异步设备接口。Qt API 以6.8文档为主要依据；第11章对关键关闭行为的说明还静态核对6.8.3实现。Windows 为主讲目标，Linux 为第二目标；这不表示已经完成任何一方的可执行验证。编译器、Qt补丁、厂商驱动和操作系统补丁的完整组合尚未经运行固定。

Qt 线程归属决定一个 QObject 在哪个线程的事件循环中接收事件，与谁拥有并销毁对象是不同关系。QThread 对象通常仍属于创建它的线程，也不等于它所管理的工作线程。停止业务资源、退出事件循环、工作对象清理和更广义的线程尾部效果需要按所用版本分别判断，不能仅用 finished 信号替代全部完成证据。

## MCU 文献身份

嵌入式说明以 NUCLEO-F446RE 开发板上的 STM32F446RET6 为主线。芯片寄存器依据 RM0390，而不是适用于其他 STM32F4 子系列的 RM0090；板卡资料以 UM1724 Rev17 及 MB1136-F446RE-C04 图纸作为文献参照。读者仍应核对实际拿到的板修订、芯片完整料号和硅版本。本版没有见到、连接或测量这套实物。

F446 主线是 Cortex-M4，不具有第18章比较说明中的 Cortex-M7 数据缓存配置。DMA 的可访问存储、外设映射与屏障条件必须回到芯片资料；跨型号代码外形相似，不意味着可以共享所有内存假设。Cortex-M7 缓存维护图明确是另一个平台条件下的机制说明。

RTOS 以 FreeRTOS Kernel V10.6.2 原生 GCC ARM_CM4F 端口为文献和 API 说明基线。实际中断优先级、可调用 FromISR 的边界、栈单位、FPU保存方式和内存分配策略，还依赖配置与端口。C++运行库初始化、异常、RTTI和动态分配策略需要项目明示，本版不预设所有功能均已启用。

## 数据值与身份

temperature_mC 使用毫摄氏度，例如25000表示25.000°C。sequence 是设备样本计数，本书基础帧使用32位无符号数并允许回绕；它不是设备身份、命令身份或永久唯一编号。generation 是主机连接会话的代际，只在主机接收上下文中使用，不能由sequence推导。

device_id 标识电子设备，boot_id 区分设备启动实例；workpiece_id 标识内部工件记录，serial_number 是外部标记或扫码追溯号，具体绑定须按产品命名空间规定。一次测试使用 attempt_id，一次设备业务动作使用 command_id，一次向外部系统提交定稿结果使用 submission_id。这些身份分别回答“哪一个设备、哪一次启动、哪一个工件、哪一次尝试、哪一次动作、哪一次提交”。

plan_version、limit_version、calibration_version 分别指测试计划、判定限值和校准关系。记录数值时应保存适用身份，而不能在复查时总套用当前版本。工位、工单和治具分别用station_id、work_order_id和fixture_id描述，错误绑定会让数值正确的结果仍然指向错误对象。

## 基础帧只承担有限责任

第4章的教学温度帧由 A5 5A 同步字节、版本、类型、负载长度、样本序号、负载和 CRC 构成。负载最多64字节，总帧长最多76字节；温度负载恰为4字节有符号小端整数。一条温度帧共16字节。这个布局按字段偏移定义，与 sizeof、结构体填充和主机字节序无关。

该帧没有携带设备身份、启动身份、状态位、校准版本或命令身份。实际会话需要额外核验这些条件，不能把通过 CRC 的一个温度数值直接用作产品放行依据。CRC 的用途是检出某些传输错误，不提供对端认证或抵御恶意修改。

source_time 是来源端时间，必须说明来源时钟域；received_at 固定表示工站接收UTC时刻。超时与经过时间使用另行命名的单调时钟观察，不能给received_at同时赋予两种时钟含义。未同步时不能直接把不同设备的时间相减而声称测得网络延迟。

## 证据的三条线

构建证据回答某套源代码与工具链能否产生预期二进制，以及静态资源是否在预算内。运行证据回答指定平台和输入条件下观察到怎样的行为。硬件测量证据还需要供电、接线、仪器、带宽、触发、参考和不确定性等条件。三者相互补充，任何一种都不能仅凭名称替代另两种。

本版的图示、代码和数值推演均保留上述区分。有关版本的原始链接与准确章节位置见第5、11、17至22章及随附修订说明。
