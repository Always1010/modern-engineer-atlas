# 完整候选版修订与来源

本报告对应《C++ 上位机与嵌入式工程入门》完整候选版0.9，编辑日期为2026年10月6日。原书基准为已验收book-v1.1.0，固定提交0842f624995d2fd99f46c68426c9a33a73610cbb。原始方案确定24章及约318页预算，允许290至340页浮动；三章样稿确认后，本版补齐其余21章并进行全书整合。

## 本轮解决的读者问题

原书覆盖58章、多条工程岗位路线。本版把学习对象收敛到工业上位机和嵌入式设备，保留必要的共用C++与工程基础，让读者能够沿一条设备数据和结果链理解概念，而不必先穿过GPU、互联网服务、机器人或AI应用路线。这里的精简靠路线取舍与关系重写，不把原书按章节机械等比例缩短。

正文以有基础编程能力、没有硬件背景的读者为起点。首次出现的对象、外设、仪器和生产术语先解释含义，再展开结构、机制、实际用途与故障。每条重点链都说明正常怎么工作、失败时能观察什么、恢复还欠哪些证据。面试内容采用已回答的追问与推理，不做空白习题、打卡计划或数量型题库。

## 已完成的内容范围

N01至N09为共用主干，覆盖系统分工、对象与资源、容器与有限内存、表示与协议、构建、并发、接口、调试验证与交付。N10至N15构成Qt工业上位机路线，按界面模型、后台采集、设备会话、PLC、质量记录和部署维护分层。N16至N22从板卡与仪器走到MCU、DMA、RTOS、恢复和嵌入式Linux。N23、N24用测试校准工站与跨层故障推理收束。

三章样稿N02、N11、N16作为写作与排版基准沿用。整合集中了必要变更：N02修订附件指引和模板类型显示；N11统一76字节整帧上限、可选设备时间字段及未验证硬件前提；N16增加两张仪器照片并明确后续文献板卡身份。接受的Qt关闭机制、硬件供电示意、安全边界和校准算例没有被扩大为实测保证。

## 共同案例与数据契约

全书使用假设的低压温度监测节点及其工站。temperature_mC、sequence、generation分别表示温度整数刻度、设备样本计数和主机连接代际。设备、启动、工件、测试尝试、设备命令和MES提交保留不同身份，避免用一个序号替代全部事实。

基本type01温度帧定义了明确的字节偏移、长度界限和CRC参数，但没有设备身份、状态、时间戳和校准版本。涉及这些条件的章节必须通过独立会话或扩展语义说明来源。N23的raw_count校准数据另属专用模式，不把基础帧temperature_mC悄悄改成原始ADC计数。

第16章用工程温度示值说明线性修正，第23章用原始计数说明另一条换算链，两组数字明确区分为独立教学输入。它们都不是测量结果。采样去重、命令重试、独立复核与MES接纳按各自确认边界处理，不把“数值在限值内”当作所有步骤已结束。
