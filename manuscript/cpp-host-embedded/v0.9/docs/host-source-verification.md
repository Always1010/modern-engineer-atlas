## 已核对但不能扩大为产品承诺

- Qt 6.8在线页面可能标6.8.9；API使用维持6.8范围，线程退出依样章6.8.3较窄静态结论。
- Modbus寄存器映射、PLC影子区/奇偶快照为教学设计，非标准或厂商自动保证。
- SQLite事务仍依日志/同步/文件系统/设备契约；未固定可执行环境。
- VIM、GUM、NIST与ILAC只支持计量概念和方法边界，示意预算不构成真实校准或认可。
- 所有代码、SQL、命令、故障序列和数字明确未执行或构造。
