# 阅读说明

这本书把现代 C++、工业上位机和嵌入式设备放在同一条工作链上：设备怎样产生数据，程序怎样解释它，测试工站依据什么作出判断，失败以后怎样保留事实并恢复。读者需要会变量、分支、循环和简单函数，不需要预先懂电路、仪器、Qt 或实时操作系统。

全书用一个低压温度监测节点及其测试校准工站贯穿说明。它是一组明确约定的教学案例，不是一套已投产产品，也不是硬件采购清单。温度节点让抽象概念有共同对象：对象生命期关系到采集任务何时能关闭，字节表示关系到负温度是否被正确解码，队列关系到记录有没有丢失，固件更新关系到掉电以后还可不可以启动。它们不必一次全部实现，却必须在同一个系统里保持相容。

## 四部分各自解决什么问题

第一部分为共用基础，包含第1至9章。先说明设备系统的分工，再讲对象与资源、有限内存、数据和协议、构建、并发、接口、故障证据与交付。第一次读到陌生工具时，先理解它提供哪类证据；不需要先安装书中提到的每一种工具。

第二部分为工业上位机，包含第10至15章。Qt Widgets 是界面主线，Windows 是主讲平台，Linux 是第二平台。重点放在设备会话、后台采集、PLC 交互、测试流程和质量追溯，而不是把所有控件列一遍。界面显示的状态必须来自已确认的业务事实；收到一串字节、完成一次写入和产品合格是不同判断。

第三部分为嵌入式，包含第16至22章。先认板卡、电路和测量工具，再讲 MCU 启动、外设、中断、DMA、RTOS、功耗与更新；最后用两章交代嵌入式 Linux 的启动、用户态应用和设备访问。MCU 文献主线采用 STM32F446 与 FreeRTOS 的明确资料基线。别的芯片、板修订、操作系统或编译器具有自己的限制，书中的结论不能只按名称相近而搬过去。

第四部分为系统收束，包含第23与24章。温度节点进入测试校准工站以后，同一份结果还要经历身份绑定、参考测量、限值判定、本地留档和业务系统接纳。末章把相似现象拆成可以用证据区分的原因，展示面试追问背后的判断方法。

## 先读一条短路线 再回到完整章节

书前的首次阅读路线从全书选出一组基础小节。它帮助建立设备、软件和生产流程的关系，按最终 PDF 的实际页码统计长度；选读部分在页面中的起止可能跨越同一页，因此页数按所涉及的不同页面计。短路线不是练习计划，也不代表读完即可独立完成硬件接线或交付工站。

读主机方向时，公共基础之后优先接第10至15章，并至少读懂第16、17章关于电气与固件的边界。读固件方向时，公共基础之后优先接第16至20章，再阅读第12、14章理解对端程序怎样解释通信和记录。走嵌入式 Linux 方向，需要继续第21、22章，但这两章不能替代专项 BSP 或驱动教材。所有路线最终都回到第23章的结果链。

## 示例 事实和验证怎样区分

语言和库规则有对应的官方资料，主要事实在章内就近标注来源，章末提供直接链接。软件片段与配置片段都用于说明机制，没有在本版中编译或运行。涉及队列容量、温度误差、持续时间、功率或故障经过的数值，除明确引用的规范参数外，都是教学假设或算式推导，不能当作测试报告。

本版没有连接真实板卡、仪器、PLC 或 MES，没有进行 Windows/Linux 双平台运行、时序、功耗、校准或安全试验。完成文稿校对、图像检查、PDF 排版或 EPUB 合规检查，只能支持相应制品质量，不能替代这些运行证据。具体哪些项目已核验、哪些没有执行，在版次说明和随附修订报告中分别记录。

## 硬件学习的安全边界

硬件例子限定为资料完整、供电与参考关系确认、由合适隔离低压源供电的受控教学设备。低压不是无条件安全：短路仍可能损坏器件或导致发热，不兼容电平仍可能烧坏输入；普通台式示波器的地夹还可能把本来不同的参考点连在一起。具体操作旁边的限制比“低压”这个名称更重要。

本书不提供市电、高压、大电池、危险运动机构或生产安全回路的初学者操作指南。发现来源不明的电源、接地、针脚或许可条件时，应先停下并查清资料。软件超时、CRC、普通 PLC 握手或界面按钮不能被当作独立的安全保护。

## 图像和代码如何阅读

机制图回答结构、顺序与责任，照片帮助辨认实物外观。照片中的设备不等于本书已选定或验证的设备，画面里的波形也不是本书测量数据。原创图、照片来源、修改情况和各自许可在书末列明；照片许可不自动决定整本书的许可。

代码先看前置条件和注释，再看语句。名称中带 demo 的接口、教学类型和示意配置需要按所在章节的契约理解；它们不是某家厂商 SDK 的未注明别名。C++ 对象的内存布局也不是通信格式，线上的字节只有按第4章约定解码以后，才成为程序中的值。
