# 阅读说明

本册收录《C++ 上位机与嵌入式工程入门》的三个样章：第二章解释程序中的对象与资源如何开始、转交和结束；第十一章把这些责任带入 Qt 后台采集和窗口关闭；第十六章把程序依赖的电源、信号和测量条件落实到板卡。

读者只需要会变量、分支、循环和简单函数。三个样章保留原定章序，便于与全书目录对应；没有收入的章节尚不属于本册正文。阅读时可按上述顺序，先建立资源责任，再理解跨线程协作，最后认识软件之外的物理条件。

共同案例是一套低压温度节点及其采集工站。temperature_mC 用毫摄氏度表达温度，例如 25000 表示 25.000 °C；sequence 表示样本序号。进程内数据对象并不是通信报文的二进制格式，照片中的开发板也不是已完成接线或验证的温度工站。

## 示例与资料的边界

C++ 片段以 C++20 的语言和库概念为说明基线；Qt 章节按 Qt 6.8 官方文档核对API，并对 Qt 6.8.3 关键退出实现做静态核对，Windows 为主讲平台、Linux 为第二平台。代码为展示机制而省略部分工程外壳，没有在本版中编译或运行，也没有完成双平台测试。读者不应将片段直接当成通过验收的可交付工程。

硬件部分只涉及资料完整、参考关系确认、由合规隔离低压源供电的教学板。仪器接线和模式限制与具体步骤一起说明；不将本册用作市电、高压、大电池或危险运动设备的操作指南。所有波形与数值推演都标明教学性质，没有板上实测结论。
