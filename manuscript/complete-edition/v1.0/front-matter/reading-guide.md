# 写在前面

软件工程的知识常被切成许多互不相连的清单：语言语法、算法题、操作系统、网络、框架、面试题。清单能告诉我们还有什么没学，却很少解释这些知识怎样在同一个系统里相遇。一个容器扩容，可能同时牵动对象生命周期、异常保证、缓存局部性与尾延迟；一次机器人转向漂移，可能来自坐标、时钟、队列和标定，而不是定位算法本身。

这本书试着把这些联系讲清楚。它以现代 C++ 和系统思维为主线，从约束、数据和机器运行出发，走到工程交付，再进入设备、服务、存储、媒体、编译器、GPU、AI 和机器人等方向。每个方向都保留自己的工作对象与限制，避免把某个领域的经验直接当作所有系统的答案。

书中的“能力地图”包含三层含义。第一层是知道概念描述什么，例如线程、事务、张量或坐标系。第二层是理解这些概念成立的条件，知道何时必须停止类比。第三层是能把判断变成可检查的证据：一个不变量、一条时间线、一份执行计划、一组误差分析，或者一次明确边界的故障复盘。

面试追问贯穿正文，但它不是背诵题库。一个答案如果只列出术语，下一步就应解释机制；如果解释了常见路径，下一步就应讨论失败；如果提出了设计，下一步就应说明如何验证。某些问题有确定的规范边界，某些问题允许不同取舍。区分这两者，本身就是工程判断的一部分。

## 读者与阅读方式

本书主要面向已经能够编写基本程序、希望建立系统知识结构的读者，也适合有项目经验但需要补齐相邻领域的工程师。它不从每一种语言的完整语法讲起，也不替代控制理论、计算机图形学或机器学习的完整课程。遇到数学与硬件知识时，正文先说明所需概念和适用条件，再给出足够支持当前推理的例子。

全书分为十三篇、五十八章。前四章建立约束、数据结构、算法与协议的共同语言；第五至二十章把机器运行、C++语义、并发和性能连接起来；第二十一至二十七章讨论构建、诊断、测试、安全与交付。后面的方向章不要求每个人全部掌握。第五十七与五十八章把知识重新组织为面试解释和项目证据。

初次阅读可以先建立公共入口：第一至四章、第七章，以及第二十一至二十六章中与当前项目直接相关的内容。以 C++ 为主的读者，再接上第五、六、八、九章与对象、容器、错误处理的基础部分。模板深层规则、无锁回收或具体 GPU 优化，不必成为所有人的入门门槛。

已有经验的读者可以从故障或交付任务进入。读到“借用”“可见性”“持久化”“时间戳”这类词时，留意它在当前层次的含义：CPU 缓存一致性不能合法化 C++ 数据竞争；请求返回不代表外部操作没有发生；日志写入不代表故障后一定能够恢复；照片里看见传感器，也不代表已经知道它的测量契约。

## 按工作对象选择方向

下面是阅读建议，不是招聘市场排名，也不要求照表读完才能开始项目。

- 固件与实时设备：第二十八、二十九章，连接第九章的资源、第十六章的同步和第二十章的测量。涉及实际电路和执行器时，还需要对应设备手册与现场安全条件
- Linux系统与网络数据面：第三十、三十二、三十三章，结合第六至八章、第十七至二十章，分别核对语言、内核和设备规则
- 桌面与上位机：第三十一章，结合第十九章的异步、第二十五章的接口与第三十三章的通信
- 服务、存储与数据平台：第三十三至三十七章，按部分失败、持久化、事务、查询和数据生命周期逐层展开；可靠运行回看第二十七章
- 音视频、图形与工业可视化：第三十八至四十章，补齐第一章中涉及的数学与第二十章的性能分析，按需要进入第四十三、四十四章
- 编译器、运行时与开发工具：第四十一、四十二章，联系第三章的图与依赖、第八章的二进制接口，以及第二十一至二十三章的交付和验证
- 科学计算与GPU：第四十三、四十四章，先明确浮点误差与并行执行模型，再讨论第四十六章的算子优化
- AI基础设施：第四十五至四十七章，把模型语义、设备计算、数值质量、排队和容量放在同一条路径上
- 机器人与自主系统：先读第五十二章的风险边界，再读第四十八至五十一章的传感、通信、估计和控制，最后回到第五十二章检查证据是否充分
- 大模型应用与Agent：第五十三、五十五、五十六章；知识检索型应用补第三十七与五十四章。工具执行、检索和多Agent并不是必须依次升级的三个阶段

每条方向都可以回到第五十七章检查自己的解释是否清楚，再用第五十八章选择一项边界合适的作品。项目的价值在于能够复现问题、解释取舍、验证结果，不在于同时堆进多少框架。

## 如何理解版本、示例与来源

C++20是本书的主要语言基线；C++23补充与C++26前沿单独说明。前沿内容使用固定草案和核验日期，不把滚动网页中的新规则反向套到旧版本。涉及Linux、Windows、CUDA、ROS、数据库和AI框架时，按章内标注的具体版本理解，不能把教材中的参照版本当作当前部署推荐。

章内来源优先采用公开规范、项目维护者文档、论文和雇主原始职位说明。一个项目的实现不能自动推广成语言保证，一条历史招聘要求不能代表整个市场。第五十七章中的职位材料用于识别工作对象和能力组合，不表示相关职位目前仍然在招。

本版没有编译、运行技术示例，也没有进行模型训练、在线API测试、性能基准或真实硬件操作。正文中的代码、容量数字和故障情境均按相应说明阅读：书面推导与教学构造不等于实验结果。实际项目需要在自己的编译器、依赖、硬件、负载和权限范围内重新验证。

原创机制图帮助理解关系与边界；有明确来源和许可的实物照片帮助认识现实对象。照片不能替代针脚手册、标定报告或安全认证。图注中的署名与许可只作用于相应图片，不表示厂商认可本书，也不自动改变其他内容的权利状态。

各章保留简明来源入口。PDF可使用目录和分层书签；EPUB可使用阅读器的章节导航；Markdown资源包保留正文与相对图片路径。三种格式承载同一版内容，固定版式页码不作为跨格式定位依据，引用时优先使用章号和节号。
