# 从路线到全貌的专题样章

样章 v0.5 · 2026-10-03

本版修订 C13 与 C55 的开篇。每篇在定义和使用背景之后分别给出行文路线与知识骨架：前者让读者知道接下来从哪些方面、按什么顺序理解主题；后者让读者先看清主题的位置、组成及关系。两张图各有职责，正文沿例子逐步展开，而非在开头堆满术语。

## 阅读入口

- [C13 从一组数据认识 vector](C13-vector-lifetime.zh-CN.md)：从一组数据的保存与使用进入，路线连接操作、存储、借用、异常、性能和工程判断；骨架把 vector 放回容器选择、使用者操作、存储管理与修改后果之间
- [C55 从语言模型到可恢复的 Agent](C55-agent-recovery.zh-CN.md)：路线先走通只读任务，再加入写入与恢复；骨架连接用户目标、模型建议、宿主执行、状态、工具和外部事实

两篇都把两种总览放在本篇开头的两页内，然后进入正文。保留逐步解释、故障诊断和面试追问，不增加学习目标、练习、自检或参考答案。章节标题和例子按主题展开，不强制使用同一种开场故事。

本版仍是两个局部专题样章，不是两个完整章节或正式出版稿；全书三卷、章节编号与范围不变。C13 以 C++20 的通常 `std::vector<T>` 为主线，不讨论 `vector<bool>` 的特殊表示；C55 使用本章的大语言模型 Agent 工作定义，MCP 固定参照 2025-11-25。
