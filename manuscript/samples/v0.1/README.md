# 第二阶段专题样章

版本：样章 v0.1。资料核验日：2026-10-03。以仓库 V1 规划基线 `d17baee8b01d180eb3117c9f58cb41348ca28964` 的稳定章节编号组织。

本组用于检验正文写法、先修桥、配图、深浅层次和练习设计。它包含两篇局部专题，不是两个已完成的全章，更不是正式出版稿。

## 从哪里读

1. [C13 从一次扩容理解 vector 的边界](C13-vector-lifetime.zh-CN.md)：设备日志的旧地址为何失效，怎样区别容量、元素、借用与身份，以及如何设计性能验证
2. [C55 可恢复的 Agent 与工具协议](C55-agent-recovery.zh-CN.md)：工单响应丢失后怎样保存未知、恢复证据、保持授权边界，并区分 MCP 协议与业务保证

每篇都包含场景、概念、未执行代码或伪代码、实现边界、性能与成本、故障排查、工程选择、六层追问、练习及答案、版本与来源。C13 连接 C09/C14/C20；C55 连接 C26/C34/C56。标题里的章节编号沿用目录，专题内部可按教学需要调整讲解顺序。

## 图与阅读格式

`assets/` 提供三幅原创 SVG；正文图片有中文替代文本，SVG 有中文 title/desc，灰度也能分辨结构。

- 编辑时保留 SVG 源和相对链接，不把截图当作唯一源
- 按 150 mm 图宽计算，C13 最小标签约 9.35 pt，C55 约 9.21 pt；小于这一宽度时应重排图或分图，不能只继续缩小
- 本轮已渲染并目视检查三幅 SVG；这不等于实际纸张、PDF 全页或 EPUB 阅读器验收
- 在线阅读可放大图并打开来源；纸面应保留同版编号、图注和参考资料。动态工具支持和实验记录适合在线材料，不能据未来配套计划声称其已经存在

## 证据边界

所有代码及伪代码均未编译或执行；没有 benchmark、故障注入实测或目标读者试读。本版没有生成新的 PDF/EPUB，也不修改仓库的发布脚本或工作流。

正文是权威可编辑源；下载源包应保留整个目录结构。来源身份和适用边界见两篇参考资料及 [来源与断言索引](source-audit.md)。质量记录见 [编辑复核总览](REVIEW.md)。

1. 不看答案，能否完成 C13 的借用判断与 C55 的恢复证据判断？卡在哪一句或哪张图？
