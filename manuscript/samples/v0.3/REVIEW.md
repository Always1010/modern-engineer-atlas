## 概念理解检查

C13 从容器身份、动态数组用途与三个整数的完整示例进入，再依次解释元素范围、连续存储、size/capacity、重新分配、引用与指针、迭代器、span 和对象生命周期。之后才讨论异步消费、异常保证、性能、故障与设计追问。

C55 先解释模型、固定工作流与 Agent 的关系，再说明工具、API、宿主程序、循环和状态。完整只读轨迹之后，才增加业务写入、未知结果、幂等和恢复。工作定义明确限定在本书语境，未把聊天界面与 Agent 对立，也未把检索增强或多个 Agent 作为必要前提。

本轮已关闭的审读问题：

- 将对象解释移到容器初定义处；明确 vector<bool> 不在本专题的通常表示范围
- 移除 C13-A 中提前出现的指针与旧借用；C13-B 使用区间的文字改为同时适用于同步与异步约定
- 为 Record、构造、生命周期、无效果保证、效果未指定及分配器补足首次出现的含义
- 区分元素扩容迁移与两个 vector 之间的移动赋值；细化无重新分配中间插入的指针、引用及迭代器失效范围
- 增加整数 vector 建立 span 的短例，再进入音频异步情境
- 在 C55-B 之前解释原操作标识；补充事务原子性的直观含义
- 修正 MCP Tasks 保留期限的绝对表述，说明 ttl 可为 null；补充取消记录可能立即删除与保存核查证据的关系

C13 以固定 N4861 条款及 N4859 版本说明复核容量、修改失效、span、尾部单元素插入的异常保证与分配器条件；工程建议、历史提案和工具文档不被当作实测结论。

C55 复核 Agent 工程定义的适用性，以及未知结果、业务身份、原子去重、第三方边界、检查点重跑、权限与批准的区分。MCP 固定参照 2025-11-25，保留能力协商、结构约束、注解信任、禁止令牌透传、实验性 Tasks 与取消边界。滚动框架资料未被当作锁定依赖或生产验证。
