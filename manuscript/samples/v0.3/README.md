# 从基本概念展开的专题样章

样章 v0.3 · 2026-10-03

本版继续校准 C13 与 C55 两篇局部专题的写法。阅读入口面向已有基本编程经验、尚不熟悉 vector 或 Agent 的读者：先说明对象是什么、解决什么问题和适用场景，再让读者沿最小例子理解工作方式，逐步进入实现、取舍与故障边界。不是给旧文添加独立术语表。

## 阅读入口

- [C13 从一组数据认识 vector](C13-vector-lifetime.zh-CN.md)：从保存三个数开始，认识动态数组、元素、容量与连续存储，再进入借用、生命周期、性能和排障
- [C55 从语言模型到可恢复的 Agent](C55-agent-recovery.zh-CN.md)：从语言模型和工具开始，走完一个只读任务，再讨论有外部影响的动作、恢复与协议边界

两篇都保留故障排查与递进的面试追问，不增加学习目标、练习、自检或参考答案。没有强制套用同一种开篇情节。全书三卷、章节编号与专题范围保持不变，本版不是两个完整章节或正式出版稿。

C13 主线为 C++20 的通常 `std::vector<T>`，不讨论 `vector<bool>` 的特殊表示。C55 采用明确范围内的 Agent 工作定义，MCP 固定参照 2025-11-25，不宣称该版本永远最新。

分章 Markdown 是权威可编辑源，`assets/` 保存四幅原创 SVG。C13-A 只呈现元素与容量，不在指针概念出现前引入旧借用；C55-A 是本版新增的执行循环图，C55-B 展示创建工单后响应丢失的时间线。图号、替代文本和 SVG title/desc 对应正文。

本版在对话中只交付 PDF，不再另附合并 Markdown 或源文件 ZIP。源稿和图源仍按版本在 Git 中维护，保留 v0.1、v0.2 历史。PDF 不加入 Git，本次不修改导出脚本、工作流、标签或 Release。
