# 结构清晰的递进专题样章

样章 v0.4 · 2026-10-03

本版继续校准 C13 与 C55 两篇局部专题的写法。保留 v0.3 已获肯定的概念入口与渐进说明，在定义、用途之后补足组成关系与行为过程，让读者先形成可以定位细节的结构，再进入例子、取舍与故障边界。新增总览不是目录或术语表。

## 阅读入口

- [C13 从一组数据认识 vector](C13-vector-lifetime.zh-CN.md)：先看容器、连续存储、已有元素和借用的关系，以及操作沿时间改变什么；随后从三个整数进入容量、有效期、异常和性能
- [C55 从语言模型到可恢复的 Agent](C55-agent-recovery.zh-CN.md)：先理解模型与工具，再看组件职责和任务生命周期；随后走完只读任务，逐步增加外部写入、恢复和协议边界

两篇采用适合本专题的分层概念标题，正文以回指连接总览与细节。故障排查与面试追问留在所需概念已经讲清之后。面试问题保留问句形式，不增加学习目标、练习、自检或参考答案，也不强制套用同一种开篇情节。

全书三卷、章节编号与专题范围不变，本版仍不是两个完整章节或正式出版稿。C13 主线为 C++20 的通常 `std::vector<T>`，不讨论 `vector<bool>` 的特殊表示；结构图不规定容器内部字段布局。C55 使用本章的大语言模型 Agent 工作定义和分析模型，不主张所有 Agent 采用统一架构；MCP 固定参照 2025-11-25。
