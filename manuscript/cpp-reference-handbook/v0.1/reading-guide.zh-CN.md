# 使用这本手册

这是一本文字紧凑的参考手册，不是按课时推进的课程。先建立“表达式—对象—所有权—容器—同步—系统接口”的联系，再按问题查规则。图解释关系；接口表给使用条件；完整例子验证一个可观察结果，不能据此推断全部实现或生产性能。

## 从零到能写小程序

第一次阅读按下面路线。遇到模板报错、网络或性能问题时，再展开查阅对应章节。

| 阶段 | 阅读 | 要能回答的问题 |
| --- | --- | --- |
| 编译与类型 | R01 → R02 → R03 → R04 | 程序如何构建？对象是什么类型？初始化与转换是否保留值？ |
| 借用与函数 | R05 → R06 → R07 | 谁拥有对象？函数和回调会不会留下悬垂引用？ |
| 资源与错误 | R08 → R09 → R11 | 拷贝还是移动？失败时谁释放资源、恢复状态？ |
| 数据与算法 | R12 → R13 → R14 → R15 → R16 | 选哪种容器？操作后什么会失效？算法前置条件满足吗？ |
| 做成可维护项目 | R27 → R30 → R31 | 库怎样参与链接和运行？怎样组织依赖并重现错误？ |

第一轮先编译 R01，修改输入并检查结果，再运行所有权、容器和算法例子。复杂度入口见 R13，结构机制紧邻相应接口。完整源码在 examples；正文局部片段明确标记，不能一律当成独立程序。

## 版本、平台和例子的边界

核心完整例子以 **C++17** 为最低语言版本；C++20 与 C++23 新接口明确标注。语言版本开关不等于标准库实现完整支持，更不等于系统 API 跨平台。编译器、标准库、链接器和操作系统分别记录，实际验证范围见 BUILD-NOTES。

- **标准保证**：可移植程序能依赖的语义与复杂度；查正文对应公开草案条款。
- **常见实现**：树节点、控制块、缓存行等帮助理解的机制，不冒充指定实现布局。
- **未定义行为（UB）**：标准不施加要求。运行一次正确、Debug 正常或未被检查工具发现，都不能证明安全。
- **实现定义**：实现需要给出选择的说明，例如部分类型与平台特性；查工具链文档。
- **未指定**：标准允许多个结果，不要求实现逐一固定；不要据观测偷偷建立接口契约。
