# C++ 与计算机基础图解参考手册目录草案

供目录审阅。面向需要从 C++ 入门并在工作中随查随用的读者；不要求已有 C++ 经验，但默认理解变量、条件、循环和函数这些基本编程概念。先用可编译的最小程序建立入口，再以规则与接口为检索单位。C++ 是主线，数据结构放在容器与算法中，操作系统、网络和组成原理只保留理解程序行为与排障所必需的部分。

## 范围与版本

语言与标准库分开组织，参考 cppreference 的分类和版本标记方式，不复制其条目，也不把手册做成标准库全量清单。正文采用常用的 C++17 能力作为兼容起点，纳入 C++20 的重要设施；C++23 内容单独标记，不默认现有工具链均支持。已废弃接口仅在遗留代码识别中出现。C++26 全量特性、完整标准措辞和冷门接口不进入本版主线。

首次阅读重点是程序结构、类型、初始化、生命周期、函数、对象、资源、容器和基础算法。工作时按目录、符号索引和故障索引直接跳转。下面的“入门必读”是必需知识块，不表示该章每一个低频条目都必须首次精读。

## 三条阅读路径

- 第一次写 C++：R01 → R02 → R03 的常用初始化 → R05 的基础借用 → R06 → R07 → R09 的 RAII 与 unique_ptr → R12 → R13 → R15 的基础区间 → R16 的查找与排序 → R28 的最小工程 → R29 的基本诊断。值类别与移动在遇到对应代码时回到 R04、R08，不用先背完全部规则。
- 接手生产代码：R05 → R07 → R08 → R09 → R11 → R13/R14 的失效规则 → R20/R21/R22 → R25/R27 → R28/R29/R30。
- 解释计算机与网络现象：R02/R05/R09 → R23/R24 → R20/R22 → R25 → R26/R27 → R30。
