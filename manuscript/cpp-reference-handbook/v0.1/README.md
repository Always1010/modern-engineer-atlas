## 内容规模与修订重点

| 内容 | 覆盖 |
| --- | --- |
| 语言与对象 | R01–R11；R02加类型性质、字节复制、placement new与存储重用；R07加子对象、多态实现模型与切片/克隆 |
| 标准库与数据结构 | R12–R19；R13–R16将复杂度、动态数组、链表、树、哈希、堆与查找/选择原理放在对应接口附近 |
| 并发与内存模型 | R20–R23；线程/锁/原子，加任务、队列、事件循环、取消与关闭协议 |
| 组成与系统 | R24–R27；CPU成本、虚拟内存、系统I/O，加目标文件、符号、动静态库、装载、搜索与ABI |
| 网络 | R28–R29；DNS/TCP/UDP/TLS/HTTP、分帧、背压、期限与幂等 |
| 构建与排障 | R30–R32；CMake、依赖、安装导出与交付、调试、性能与资源证据 |
| 图与例子 | 44幅可编辑SVG；29个根目录单文件程序，另有CMake静态库工程和STATIC/SHARED/MODULE关联工程 |

完整程序以C++17为基线；C++20/23设施单独标注。新例子验证对象重用、算法关系、队列拒绝/异常/排空，库工程验证Windows x64的三种使用方式与插件失败路径。正文与独立源码、R13片段、R30工程及R27接口摘录由工具核对。

本轮没有重新运行所有历史程序，也没有实测Linux端点、MSVC或协程框架。TDM-GCC插件需选用共享运行库并部署已有匹配DLL；初始卸载失败、修复与范围见[库工程记录](examples/r27-libraries/README.md)。系统与新标准设施的完整边界见BUILD-NOTES。
