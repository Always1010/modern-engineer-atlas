# C++ 参考手册条目与编写规范

本书同时提供首次学习和按对象查阅两条路径，共用一份正文。知识组织以类别、具体对象和操作为基础，先解释正常写法，再展开机制与例外。

## 规范入口与复用

[技术文章与书稿风格规范](../../../docs/technical-article-style.md)维护本轮用户确认的通用规则：结构与行文、加粗判断及示例、英文与代码符号、版本提示、表格、字体、颜色、分页、资料链接和复用检查。本书采用该规范；本文件记录本书的条目职责、技术基线、源ID、目录模型与核验约束，并对通用规则作书稿内的落实说明。

用于其他文章时，引用通用规范并填写目标文章自己的参数。不要照搬本书7章35节、R编号、C++17基线或本轮验收数量。正文强调以语义为依据；复查同级对象有无漏标，不通过批量加粗术语补齐。

## 范围与章节职责

全书采用7章、35节、带编号小节三级结构。七个知识领域为章，现有35个R源文件分别承载一节。内部R编号是稳定来源标识；读者编号由catalog的章、节顺序生成，源文件与锚点不随显示编号改名。R18 分为文本处理与 R33 数值/随机/位工具；R19 分为时间库、R34 流与文件读写、R35 文件系统。R06、R14、R23 使用明确的知识组和具体对象条目。

基础内容以 C++17 编写；C++20/23 单独标版本。历史引入版本与示例编译基线分别说明。低频条目可只索引，但必须明确范围，不把提过名字算作已展开。

生命周期定义归 R02，借用归 R05，类生命周期归 R07，资源所有权归 R09；值类别与移动归 R08，模板转发及类型特征归 R10。placement new 的存储重用归 R09，类初始化机制归 R07；基础初始化与普通类型推导归 R03。时间类型归 R19；期限在并发和网络章只解释各自等待/重试语义。字节序机制归 R24，标准工具归 R33；平台 I/O 归 R26，调度模型归 R23。二进制与装载归 R27，构建操作归 R01/R30，调试与性能分别归 R31/R32。

## 目录与条目

章组织知识领域，节组织知识群，小节是具体对象或明确规则。源稿H1在阅读制品中显示为节（如1.3），H2显示为小节（如1.3.1），H3显示为不编号的局部标题。章首页提供本章各节目录；节首说明分类和先修，提供基础阅读入口。标题使用专业名称，不写劝告式口号。

正文不显示重复的内容分类标签。内容顺序与标题表达层级。首次定义术语给中文、必要英文/缩写和一句定义；版本、平台另行说明，不将新版等同进阶。其他节可回链到定义；会影响当前操作正确性的条件仍就地说明。

正文加粗仅用于正在定义的概念或代码符号，以及明确对比中的同级对象或差异结果。定义中的英文译名、重复提及、普通解释、条件和限制不额外加粗。对比根据差异选择强调对象或结果，不同时加粗整句所有名称与结论。普通行内代码呈蓝色常规字重；定义或对比位置才显式加粗。不得按术语词典、首次出现或主观重要程度自动加粗。表格正文无加粗及代码强调色，表头保留结构字重。

### 语言规则

名称与定义 → 语法形状 → 常用写法 → 结果与条件 → 典型差异 → 机制/例外 → 相关条目。初始化类别允许相互关联，不伪造完全互斥分类。类型大小/范围区分标准要求、具体 ABI 和查询方法。

### 标准库类型与接口

类别、用途、头文件/版本 → 公开声明摘要及模板参数 → 构造/初始化 → 常用接口组 → 参数、返回值/状态变化、前提 → 短例 → 机制与相关符号。函数条目省略不适用的构造字段。声明摘要注明省略，不冒充完整实现。

每个重点类型独立入口；共享接口可集中维护，但类型差异及基础短例必须可查。重载按语义分组：数量、范围、初始列表改变含义时分别展示；只列函数名不算覆盖。容器交代复杂度及引用/指针/迭代器失效，锁交代所有权与阻塞，视图交代实际所有者。

### 系统与协议

实体定义/分类 → 结构或过程 → 正常操作/交互 → API、报文或状态 → 必要条件 → 调查入口。区分语言、标准库、常见实现、OS 和协议保证。Linux/Windows 流程分别给出，不混写成伪跨平台接口；协议章使用报文和流程，不强制 C++ 程序。

### 工具与工程操作

用途及适用环境 → 输入/准备 → 命令或操作 → 结果 → 常用参数 → 诊断与扩展。命令使用相对文件名；私人绝对路径、QA 脚本和测试过程退出正文。调试必须有最小会话，性能必须有测量过程和真实结果边界。

## 正文与代码

每段新增定义、分类、操作、结果、条件或机制之一。删除泛泛工程提醒和重复限制；一项总论只有一个主要维护位置。不能为了简短删除有效性条件，不能靠增加综合程序代替接口覆盖。

- 操作短例通常 3—12 个有效语句，先说明用途，后说明结果或状态。
- 机制例通常 10—30 行，只展示解释所需关系，配图或文字。
- 完整程序/小工程保存在 examples，正文提供链接和重点说明；确需正文展示的摘录使用 source 标记核对。保留有效旧程序，不强制全文嵌入。

示例以解释标准接口和语法为目的，不强制提供完整 main 或实际执行。代码块不附固定类别标签，也不重复解释标签。根据实际依赖提供必要的具体说明，不因围栏紧邻就认为可连续执行。声明摘要不作标准库重新定义；承接摘录写明依赖与替代关系，跨线程代码标明共享定义与角色路径。局部摘录注明头文件与已有对象；可选初始化分段或使用不同变量名。重要调用使用 fenced 代码，避免长行内代码。并发不承诺输出顺序，平台/实现相关结果明确环境。不得运行未定义行为来证明规则。

## 表格与图

表格只承担比较或查询任务，同类实体作为行，一致属性作为列。通常 3—4 列；过宽或长段单元格先拆分。构造表按形式/代码/状态；接口表按名称/参数结果/条件；详细签名和短例在条目中展开。流程改为编号步骤、流程图或时序图，不机械替换有效对比表。

图分别回答分类、结构、流程/时序、状态变化。使用可编辑静态 SVG，具有 title/desc；图标签必须已定义。图与正文相互补充，图数不作为指标。失效/删除的图同时清理引用。

## 全书样式与导航

打印版每章和每节从新页开始：第1章与1.2之类的节各自另起一页；1.2.1之类的小节以及不编号的局部标题随正文连续排版。公共 CSS 统一实现，不在各节源稿插入手工分页符。

公共CSS和排版转换由全书及新的局部审阅制品共用，屏幕/打印规则分开，不按章号临时压缩间距。历史v2—v5样章作为对照保留。全书采用蓝色体系，不使用绿色装饰或类型着色。正文中文宋体，标题黑体，正文英文与行内代码Segoe UI，代码块Consolas；代码浅蓝背景、关键字蓝色、基础类型紫色、数字棕色、注释灰色。编号与对应标题同字体、同字号、同字重。段首明确限定适用范围的版本用蓝灰细边框标签，句中版本普通英文样式。A4 正文约 10.5—11 pt，表格/代码约 9 pt，参数经实际页图校准。宽表先拆，短代码尽量完整放置，长代码按逻辑允许分页；标题不孤立，续表重复表头。黑白打印可区分层级。

HTML提供章、节和小节导航，中文/英文概念、库符号、头文件、任务、工具命令索引均指向实际条目。稳定锚点由标题生成，同章重复标题必须消歧；本地带片段链接不能退化为章级链接。

正文是知识事实来源，catalog 保存目录与迁移元数据，TOC/索引依据实际标题同步。来源 R 编号与读者章序分离；旧来源条目保留、重写、拆分、迁移或删除都有去向。

## 来源、协作与验收

cppreference 用于分类与检索参考；语言和库规则使用匹配版本公开草案，系统/协议/工具优先官方资料。用于资料依据的外部链接移至sources/Rxx.references.json，按稳定源ID、原条目标题、标签和URL维护；正文不显示段尾资料链接或章末来源堆叠。具有实际任务用途的配套文件和工具入口可以保留。资料核对与平台运行明确区分。

主编辑维护共享规范、catalog、目录、索引、CSS、构建说明；正文按互不重叠的知识群分配。样例覆盖语言、库、系统和工具后再推广。任何旧样章均需按当前标准复审。

验收检查对象独立入口、正常写法、参数结果、必要条件、层级、重复归属及读者任务。按用户要求，代码只做静态语法与资料核对，不编译运行示例或测试程序；不以 Windows 本机行为推断可移植语义，不为核验更换工具链。核对源码摘录、链接、图源和元数据；内容稳定后生成全书 HTML/PDF 并检查页图。功能变化直接改当前说明，历史检查在 BUILD-NOTES 与 Git 中可追溯，不将旧检查冒充本轮结果。
