## 内容与编辑

语言规则与对象资源、标准库及数据结构、并发、组成与系统、网络、工程与调查分别维护。文本与数值工具分节，时间库、流、文件系统各自成节。完整源码保存在examples，短摘录服务于接口查阅；代码按用户要求做静态核对，不要求实机编译运行。

正文、图源、例子、catalog、目录、索引和工具纳入Git。output与qa为忽略的生成产物，全新检出需用已有依赖重建。唯一编辑版本为本目录；阅读制品不能代替源文件，源码链接需要配套目录。
