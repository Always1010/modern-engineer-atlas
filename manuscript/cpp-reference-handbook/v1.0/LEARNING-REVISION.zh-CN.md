# v1.0 学习顺序修订与验收

2026-10-10。用户确认本轮正式版本为 v1.0；正文目录由 v0.2 迁至 v1.0，原 R 源 ID 保持。全部助手使用 GPT 6.1 sol，主编维护整合、导航、样式与阅读制品。本轮承接已确认样稿及章、节另起一页的排版要求。

## 内容与阅读路径

全书7章35节逐节审查。语言入口从整数初始化、赋值和按值推导开始；普通函数先于指针/引用，类构造析构先于复杂初始化，独占资源先于完整移动，函数模板与推导先于转发。标准库先建立元素、长度、容量与位置模型，再进入区间、插删与失效；迭代器、算法先于关联容器。系统、协议和工程章节保留已经合理的主线，并补死锁、非原子访问、异步信号安全、fd/HANDLE等实际需要的局部定义。

[使用指南](reading-guide.zh-CN.md)提供七阶段具体入口、理解检查与按任务查阅路线。每章、每节从新页开始，1.2.1之类的小节与局部标题连续排版；共享 CSS 统一实现。头文件说明按实际首次使用和依赖变化组织，清理重复“局部例子”标签。
