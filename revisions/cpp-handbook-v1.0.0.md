# C++ 与计算机基础图解参考手册 v1.0.0

首次独立发行当前 v1.0 学习顺序修订版，包含 7 章、35 节，以 C++17 为核心，分别标记 C++20/23 扩展及平台接口。

## 下载与阅读

- PDF：A4、可检索文字、书签和内部导航，目录与索引提供实际页码。
- HTML：全书导航、内嵌 SVG；配套源码链接指向本发行标签下的 GitHub 文件。
- bundle.zip：PDF、离线 HTML、examples 配套源码、sources 来源记录、字体权利说明和构建记录。解压后打开 handbook.html，源码链接使用包内相对路径。
- build-info.json：源提交、工具及字体版本、检查范围和源文件摘要。
- SHA256SUMS.txt：核验上述四个附件的 SHA-256。

PDF 中的外部源码链接需要联网；离线时直接查阅配套包中的 examples。此发行的手动上传附件只包含参考手册。GitHub 自动提供的 Source code ZIP/TAR 是整个仓库的标签快照。

## 核验范围

发布流程检查源稿结构、目录索引、源码摘录、迁移覆盖、样式、HTML 锚点、PDF 分页及字体嵌入、文字及页面边界、全页渲染、配套链接和附件摘要。PDF 链接转换另核对页内容、书签、命名目标及链接数量保持一致。

C++ 示例只做静态核对，不编译或执行；这些检查不证明任意并发交错、所有平台接口或各厂商标准库行为。全新检出不包含历史本地审查基线，构建记录明确区分这项检查。

字体许可不延伸为整本手册的许可；项目未指定统一再授权条款。
