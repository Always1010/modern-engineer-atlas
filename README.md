# 工程技术书籍与参考手册

本仓库收录围绕现代 C++、计算机基础与软件工程实践编写的中文书籍。每本书在自己的分支维护正文、示例、素材、构建工具与版本记录；`main` 提供书籍介绍、阅读入口和已发布版本。

## C++ 与计算机基础图解参考手册

面向已有基本编程经验、希望理解 C++ 规则与计算机运行机制的读者。通过分类、具体对象、常用写法和图解组织内容，方便按对象、规则和任务查阅。

当前书稿为 v1.0 学习顺序修订版，包含 7 章、35 节。核心以 C++17 组织，C++20/23 与平台接口分别标记。分支中的书稿会继续更新，发行版保存对应标签的内容快照。

## 现代软件工程师能力地图

面向已有基本编程经验、希望建立完整工程知识体系的软件工程师。以现代 C++ 与系统思维连接语言基础、机器运行、工程实践与岗位能力，围绕机制解释、设计取舍、故障诊断和工程证据展开。

正文包含 13 篇、58 章、232 个主题，覆盖公共基础、现代 C++、并发与性能、可靠交付，以及嵌入式、服务与数据、音视频与图形、编译器、HPC 与 GPU、AI 基础设施、机器人和 LLM 应用等工程方向。
